# 🧾 알바영수증 (Alba Receipt)

아르바이트·단시간 근로자의 **이번 달 예상 급여**를 영수증 모양으로 계산해 주는 웹앱입니다.
2026년 최저임금과 4대보험 요율을 반영하고, 통장에 실제로 들어온 금액과 비교해 **덜 받은 돈**까지 확인할 수 있습니다.

- 라이브: https://alba-receipt.vercel.app
- 스택: Next.js 15 (App Router) · TypeScript · Tailwind CSS 3 · Vercel
- 서버·DB 없이 모든 계산이 브라우저에서 실행됩니다. 입력값은 `localStorage`에만 저장됩니다.

## 기능

| 구분 | 내용 |
| --- | --- |
| 최저시급 | 2026년 10,320원 / 2027년 10,700원 원클릭 리셋 (월 209시간 환산 각 2,156,880원 · 2,236,300원) |
| 근무시간 | 주 근무일수 × 하루 근무시간, 또는 주당 총 시간 직접입력 |
| 휴게시간 | 하루 0 / 30 / 60분 / 직접 입력 — 무급으로 주 소정근로시간에서 자동 제외 |
| 주휴수당 | 주 소정근로 15시간 이상 && 개근 가정, `(주 소정근로 ÷ 40) × 8시간 × 시급`(최대 8시간) |
| 공제 | 3.3% 원천징수(소득세 3% + 지방소득세 0.3%) · 4대보험 9.7% · 미적용(0%) |
| 4대보험 | 국민연금 4.75% + 건강보험 3.595% + 장기요양(건보료의 13.14%) + 고용보험 0.9% |
| 가산수당 | 5인 이상 사업장에서 연장 50% · 야간(22:00~06:00) 50% 가산, 5인 미만은 가산 의무 없음 안내 |
| 수습 | 시급 90% 토글 — "1년 이상 계약 + 수습 3개월 이내, 단순노무직 제외" 안내 포함 |
| 실제 입금액 비교 | 통장 입금액과 예상 실수령액의 차액 계산, 부족 시 사장님께 보낼 확인 메시지 복사 |
| 영수증 | 모노스페이스 영수증 카드 + 톱니바퀴 마감 + 클립보드 복사 |
| SEO | 메타데이터 · OG · FAQPage/WebApplication JSON-LD · robots.txt · sitemap.xml |

## 계산 규칙

- 월 환산: `1년 365일 ÷ 12개월 ÷ 7일 = 4.345주`. 시간은 항목별로 정수 반올림해 월 환산한다.
  - 주 40시간이면 기본급 40 × 4.345 ≒ 174시간 + 주휴 8 × 4.345 ≒ 35시간 = **209시간** → 최저임금 월 환산액과 일치.
- 야간근로 시간은 근무(소정·연장) 시간에 포함된 것으로 보고 **가산분(0.5배)**만 더한다.
- 4대보험 모드에는 근로소득세(간이세액표)가 포함되지 않는다.

## 개발

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 프로덕션 빌드
npm run verify     # 계산 로직 테스트 (node --experimental-strip-types --test)
```

계산 로직은 `src/lib/pay.ts`의 순수 함수로 분리되어 있고, `tests/pay.test.ts`에서
2026 최저시급 209시간 환산, 주휴 15시간 경계, 휴게시간 차감, 4대보험 9.7%, 3.3%,
5인 이상/미만 가산, 수습 90%, 실제 입금액 차액을 검증한다.

## 배포

GitHub `main` 브랜치에 push하면 Vercel이 자동 배포한다.
사이트 URL이 바뀌면 Vercel 환경변수 `NEXT_PUBLIC_SITE_URL`만 바꾸면 canonical·sitemap·robots에 반영된다.
